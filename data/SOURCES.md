# Data sources

Registry of every data source used in this repo. Add a row **before** downloading
or committing any data from a new source. Rules: [CLAUDE.md §7](../CLAUDE.md).

- **Redistribution allowed:** `yes` / `no` / `unclear`. If `no` or `unclear`, raw data
  stays out of git and the analysis ships a `download.py` instead.
- **Quality:** `primary` (registries, regulators, filings) / `specialized press` / `blog`.
- **Access date:** `YYYY-MM-DD`.
